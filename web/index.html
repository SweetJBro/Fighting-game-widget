Bring your own ROM

This lobby does not ship or download any game data. Pick your own Street Fighter III: 3rd Strike FBNeo romset. The file stays in this browser (IndexedDB) and is never uploaded anywhere.

This server packages its owner's Street Fighter III: 3rd Strike romset for personal use, so you can play right away. It is the Japan 990512 NO-CD set that Fightcade runs, with the same Region (Japan) and CPU (100%) settings. Storing your own set below is optional; a stored set takes precedence and stays in this browser (IndexedDB).

Accepted set names: sfiii3nr1.zip (Japan 990512, no CD, the Fightcade standard), sfiii3n.zip, sfiii3r1.zip, sfiii3.zip. The zip must keep its original set name so FBNeo recognises it, and it must be a full set (roughly 65–80 MB depending on compression) that already contains the shared sfiii3-simm2.x to simm6.x files. Fightcade's split pair can be merged with scripts/merge-romset.py.

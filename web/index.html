Bring your own ROM

Only the host of a match needs the game; people who join or watch need nothing. To host , pick your own FBNeo romset, for example straight from Fightcade's ROM folder. Files stay in this browser (IndexedDB) and are never uploaded anywhere.

This server packages its owner's romset for personal use, so you can play right away. Storing your own set below is optional; a stored set takes precedence and stays in this browser (IndexedDB).
